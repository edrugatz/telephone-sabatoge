# Playtest backlog

Feedback sent from the game's 💬 button (SPEC §10 Feedback) lands in Firebase `feedback/`.
`npm run feedback` prints the entries that aren't here yet; they are pasted under **🆕 New**.

**Triage, in a session:** go through 🆕 New together. For each entry, decide:
- ✅ **Accepted**: move it to Accepted, write what we'll do. When it's done, mark it 🔧 fixed (with the commit) and move it to Done.
- ❌ **Rejected**: move it to Rejected, with the reason.

The `<!-- feedback-id: … -->` line is how the script knows an entry is already here: keep it when moving an entry.
